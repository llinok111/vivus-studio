vivus studio · svg motion timeline

把「一次性描边动画」
扩展成关键帧时间轴

上游 vivus 只会在加载时把 SVG 描一遍，没有变形、没有图标过渡、没有时间轴，也不能擦洗。 这一版补上了这些能力，并且导出的 SVG 不依赖任何脚本即可播放。

上游能力 vs 本版

能力vivus 0.4.6vivus studio
描边绘制支持（一次性，按帧计数）支持（时间轴轨道，可擦洗、可倒放）
路径变形无任意命令混用：圆弧转三次贝塞尔、段数补齐、起点重定、子路径配对
图标过渡无路径数不一致也能过渡：多出的子路径收缩到重心
关键帧无多轨关键帧 + 22 条缓动 + 逐段可调
动画中断只能 stop / reset零跳变重定向：中断时把当前值固化为锚点，可选保持速度
缩放非等比缩放需手动 recalc()pathLength 归一化，任意尺寸下 dash 长度自动跟随
导出无独立 SVG（SMIL）+ 独立 HTML 播放器，均可离线运行

三个真实案例

描边绘制

五条描边错峰落墨，附整体回弹。验证 dash 数学在 4 倍缩放下仍然闭合。

路径变形

圆 → 方 → 星 → 圆。验证圆弧转换精度与起点对齐，避免扭转伪影。

图标过渡

菜单三横线 → 关闭叉号。验证路径数不等的配对与塌缩策略。

本地运行

# 依赖只有构建与测试工具；运行时零依赖
npm install
npm run build:studio        # 打包编辑器 → studio/app.bundle.js
npm run serve               # http://127.0.0.1:4173/studio/

npm test                    # 27 单元 + 89 上游 + 46 浏览器断言
node tools/build-demo.mjs   # 重新生成 demo/ 下的导出文件
